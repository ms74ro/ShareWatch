Choose the language folder

The texts come from the language files (en.json, de.json, …) in the folder where this page is. A browser does not let a page read files by itself, so choose that folder once; it is remembered in this browser. Nothing is uploaded: the page only reads the files on your computer. You can also drag the .json files here.

Write the translation under each text. Keep {0}, {1} where they are (the program puts names and numbers there). Your work is kept in this browser until you press Clear. When done, press Download .json and put the file in the language folder next to ShareWatch.exe, then restart ShareWatch and pick the language in Options → Language. Texts left empty are shown in English.
